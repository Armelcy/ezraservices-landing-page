Réinitialisation du Mot de Passe

Ouvrir dans l'Application

Pour des raisons de sécurité, la réinitialisation du mot de passe doit se faire dans l'application mobile Ezra.

Ouvrir l'App Aide
Instructions Manuelles
1. Ouvrez l'application Ezra sur votre téléphone
2. Appuyez sur "Mot de passe oublié" sur l'écran de connexion
3. Saisissez votre adresse e-mail
4. Suivez les instructions dans l'e-mail que vous recevrez
