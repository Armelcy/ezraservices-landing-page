Avant de supprimer votre compte

⚠️ Attention : La suppression de votre compte est irréversible. Toutes vos données personnelles seront définitivement supprimées de nos systèmes.

Ce qui sera supprimé :

  • Informations de profil : Nom, prénom, photo, biographie
  • Coordonnées : Email, numéro de téléphone, adresse
  • Historique : Réservations passées, recherches, préférences
  • Messages : Conversations avec les prestataires/clients
  • Évaluations : Avis et notes donnés ou reçus
  • Données de paiement : Méthodes de paiement enregistrées
  • Informations de vérification : Documents d'identité (pour les prestataires)

Ce qui sera conservé :

  • Données légales : Les transactions financières seront conservées pendant 7 ans conformément aux obligations légales
  • Données anonymisées : Certaines statistiques peuvent être conservées de manière anonyme pour nos analyses

Délai de traitement

📅 Délai de suppression : Votre compte et vos données personnelles seront supprimés dans un délai de 30 jours après validation de votre demande.

Vous recevrez un email de confirmation une fois la suppression effectuée.
